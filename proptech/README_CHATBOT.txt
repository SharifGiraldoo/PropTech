  CHATBOT IA — CONFIGURACIÓN (2 minutos, gratis)
════════════════════════════════════════════════════════════

1. Ve a: https://aistudio.google.com/app/apikey
   (inicia sesión con tu cuenta de Google)

2. Haz clic en "Create API key" → copia la key (empieza con AIza...)

3. Abre el archivo "config.properties" y reemplaza:
      GEMINI_API_KEY=TU_KEY_AQUI
   por tu key real:
      GEMINI_API_KEY=AIzaSy...tuKeyAqui

4. Ejecuta normalmente:
      java -jar target/proptech.jar

¡Listo! El chatbot funcionará automáticamente.

GRATIS: 1500 consultas/día, sin tarjeta de crédito.
